# Dashboard ยอดขาย · บ้านสบาย ช็อป

Dashboard จากคาบ 3 (W3-A/B) ย้ายจาก Artifact บน claude.ai มาเปิดในเครื่องได้โดยไม่ต้องต่ออินเทอร์เน็ต

## วิธีเปิด

1. ดับเบิลคลิก `index.html` (เปิดด้วย Chrome หรือ Edge)
2. กดอัปโหลด `data/orders.csv` และ `data/products.csv` ถ้าต้องการดู % กำไรขั้นต้น

ข้อมูลไม่ได้ฝังอยู่ในโค้ด หน้าเว็บอ่านไฟล์ CSV ที่อัปโหลดในเบราว์เซอร์เท่านั้น

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บและ CSS |
| `app.js` | โค้ด dashboard (คำนวณ กราฟ ตัวกรอง บทสรุปผู้บริหาร) |
| `react.js`, `react-dom.js` | React 18.3.1 |
| `htm.js` | htm 3.1.1 ใช้เขียน JSX ได้โดยไม่ต้อง build |
| `papaparse.js` | PapaParse 5.4.1 อ่านไฟล์ CSV |
| `fonts/` | ฟอนต์ IBM Plex Sans Thai |

## ต่างจากเวอร์ชัน Artifact

- ปุ่ม "ดาวน์โหลดรายงานสำหรับทำ PDF" ใช้ระบบดาวน์โหลดของเบราว์เซอร์แทน `window.claude` ซึ่งมีเฉพาะบน claude.ai
- ไฟล์รายงานที่ดาวน์โหลดยังโหลดฟอนต์จาก Google Fonts ถ้าเปิดแบบไม่มีเน็ตจะใช้ฟอนต์ของเครื่องแทน
